■ サイドバーの追加手順と機能一覧

新しくカテゴリ専用のサイドバーを追加する場合、以下の手順で作業を行ってください。
サイドバーの管理は `src/components/sidebars/index.ts` で一括して行っています。

============================================================
【手順1】サイドバー用コンポーネントの作成
============================================================
場所: src/components/sidebars/
ファイル名の例: `MathSidebar.astro` など

既存の `PhysicsSidebar.astro` を参考にして、以下のように構成を定義します。

```astro
---
// src/components/sidebars/MathSidebar.astro
import Sidebar from "./Sidebar.astro";

const config = {
  title: "数学メニュー",
  category: "math", // カテゴリID。指定するとタイトルがそのトップページへのリンクになります。
  items: [
    { type: "group" as const, name: "微分積分" },
    { type: "group" as const, name: "線形代数" },
    { type: "link" as const, label: "公式集(外部)", url: "https://example.com" }
  ]
};
---
<Sidebar {...config} />
```

============================================================
【手順2】index.ts への登録
============================================================
ファイル: src/components/sidebars/index.ts
このファイルを開き、以下の2ステップで登録します。

1. 作成したコンポーネントをインポートします
   `import MathSidebar from "./MathSidebar.astro";`

2. `SIDEBAR_MAP` の連想配列に、`category_id` をキーにしてコンポーネントを追加します
   ```ts
   export const SIDEBAR_MAP: Record<string, any> = {
     physics: PhysicsSidebar,
     math: MathSidebar, // <- 追加
   };
   ```

これだけで、該当するカテゴリの記事やトップページを開いたときに自動的にこのサイドバーが表示されます。

============================================================
【機能一覧】サイドバーで使える書き方
============================================================
`Sidebar.astro` に渡す `items` 配列の中には、以下の4つのタイプの要素を自由に配置できます。

1. **自動グループ分類 (`type: "group"`)**
   - `{ type: "group", name: "グループ名" }`
   - 指定した `category`（例: "physics"）と、記事のフロントマターに設定された `group`（例: "力学"）が一致する記事を自動で収集し、リンクをリスト表示します。
   - 記事の `order`（フロントマターで指定）の昇順で自動ソートされます。

2. **手動グループ分類 (`type: "custom-group"`)**
   - `{ type: "custom-group", name: "特別グループ", posts: ["physics/post-1", "tech/post-2"] }`
   - カテゴリやグループの制約に関わらず、指定された記事ID（スラッグ）の記事をリストとして表示します。他カテゴリの記事を混在させることができます。

3. **個別記事リンク (`type: "post"`)**
   - `{ type: "post", id: "physics/post-1" }`
   - グループの見出しを付けず、特定の1つの記事へのリンクを直接リスト内に表示します。

4. **カスタムリンク (`type: "link"`)**
   - `{ type: "link", label: "外部リンク", url: "https://...", description: "説明文(任意)" }`
   - 外部サイトやブログ内の任意のページへのリンクを自由に設置できます。
